# 🚘 內湖平日晨尖峰內科車流熱力儀表板與政企協商決策系統
> **Neihu Traffic Heatmap Dashboard & Corporate Negotiation Platform**
> 
> 結合開放資料（TDX / VD 車輛偵測器）、主觀「體感塞車指數 (PTCI)」演算法與 ESG Scope 3 減碳引擎，提供臺北市政府與內科企業推動「分批上班、彈性工時」的數據後盾。

---

## 📌 專案背景與市政痛點

平日 `07:00–09:30`，數萬輛汽機車集中湧入成美橋、民權大橋與堤頂大道等關鍵聯外廊道進入內湖科學園區。傳統交通監測僅關注客觀流量與容量比（V/C），難以量化駕駛人在打卡生死線前的心理焦慮與走走停停衝擊波。

本專案旨在將每 15 分鐘湧入內湖的車流熱點攤在陽光下，結合動態視覺化儀表板與互動式 Web App，精算企業推行「**核心工時 (10:00–16:00) ✕ 三分流到勤**」對通勤時間與 ESG 範疇三減碳的實質效益。

## 🧮 核心演算法：「體感塞車指數」(PTCI)

交通工程的客觀容量比（V/C）無法完全還原駕駛主觀痛苦。本系統導入非線性「體感塞車指數 (Perceived Traffic Congestion Index, PTCI)」：

$$\mathbf{PTCI} = \min\left(100, \; 100 \times \left[ w_1 \cdot \left(1 - \frac{v_{\text{act}}}{v_{\text{free}}}\right)^{\alpha} + w_2 \cdot \left(\frac{V}{C}\right)^{\beta} + w_3 \cdot \left(\frac{\text{Occupancy}}{\text{Occ}_{\text{crit}}}\right) \right] \times W_{\text{time}} \right)$$

### 變數與權重配置：


* **車速落差感** ($1 - \frac{v_{\text{act}}}{v_{\text{free}}}$)：敏感度次方 $\alpha = 1.5$，$w_1 = 0.45$。車速降至速限 30% 以下時，延滯感呈指數暴增。
* **容量壓迫感** ($\frac{V}{C}$)：飽和次方 $\beta = 1.2$，$w_2 = 0.35$。當 $\frac{V}{C} \ge 1.0$ 時帶來空間窒息感。

* **走走停停衝擊波** ($\frac{\text{Occupancy}}{\text{Occ}_{\text{crit}}}$)。

* **test** ($\text{Days}_{\text{work}}$)
* **晨尖峰時間壓力加權** ($W_{\text{time}}$)：`08:00-08:45` 打卡生死線加權 $W_{\text{time}} = 1.25$；`07:30-08:00` 加權 $1.10$；其餘時段 $1.00$。

## 🚦 短、中、長期解決方案總覽

* **短期方案 (0–1年)**：
  1. 企業「核心工時 (10:00–16:00)」與三分流到勤獎勵（最尖峰車流降 10–12%）。
  2. VD 即時數據串接與幹道動態綠廊連鎖 (ITS)。
  3. 捷運接駁直達快線專車精準升級（松山、士林、南港展覽館站）。
* **中期方案 (1–3年)**：
  1. 尖峰動態累進停車費率與高乘載 (HOV 3+) 免費優惠。
  2. 瓶頸路口幾何改善（拓寬交織段、偏心左轉專用道）。
  3. 綠色微移動（YouBike 2.0 / 自行車專用道）路網串聯。
* **長期方案 (3–10年)**：
  1. 捷運環狀線東環段與民生汐止線完工通車（公共運輸分向比提升至 60–65%）。
  2. 興建地下穿越性快速道路，實現地表與地下車流分層分離。
  3. 內科土地混合利用轉型（TOD 高密度開發與園區社會住宅，落實職住鄰近）。

## 🌿 ESG Scope 3 減碳算力模型

企業推行彈性工時避開晨尖峰低速怠速，屬 **GHG Protocol 範疇三 (Scope 3 - Category 7 員工通勤)** 盤查範疇。

### 算力公式：
$$\Delta \text{CO}_2 = N_{\text{commuters}} \times D_{\text{commute}} \times \left( E_{\text{peak}} - E_{\text{offpeak}} \right) \times \text{Days}_{\text{work}}$$

* **1,000 人企業實例 (30% 參與率)**：
  * 每日避免怠速與起步走走停停，單人節省 18.5 分鐘。
  * 每日減碳約 **238.74 kg CO₂e**。
  * 每年（250 工作日）減碳 **59.69 公噸 CO₂e**（相當於每年造林約 **4,973 株樹木**）。

## 💻 快速開始與執行方式 (Quick Start)

### 1. 安裝必要套件
```bash
pip install pandas numpy matplotlib seaborn plotly streamlit
```

### 2. 運行 Streamlit 互動式 Web App
```bash
streamlit run neihu_traffic_streamlit_app.py
```

### 3. 執行 ESG 減碳 CLI 試算腳本
```bash
# 預設參數試算 (1,000人企業)
python3 esg_carbon_reduction_calculator.py

# 自訂企業參數試算 (2,000人企業, 40%參與率, 汽車佔50%)
python3 esg_carbon_reduction_calculator.py --employees 2000 --participation 0.40 --car_ratio 0.50
```
